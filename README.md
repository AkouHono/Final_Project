# Final_Project
This project explores global COVID-19 vaccination trends using publicly available datasets.
It provides insights into vaccination coverage, disparities between countries, 
and rollout patterns over time through visual storytelling and data analysis.

Objectives

Clean and preprocess large-scale vaccination data

Analyze vaccination coverage and rollout timelines by country

Build interactive visualizations (line charts, bar plots, and choropleth maps)

Highlight anomalies and global disparities

Tools & Technologies

Python: Pandas, NumPy, Matplotlib, Seaborn, Plotly

Jupyter Notebook for analysis and documentation

Choropleth maps for global vaccination coverage

Markdown for narrative explanations
Key Insights

India leads in absolute doses but still faces coverage challenges due to its large population.

Smaller nations like Seychelles achieved 70%+ full vaccination early in the rollout.

Global vaccine distribution remains highly uneven, with low-income countries lagging.

Booster campaigns in 2021–2022 dramatically changed the vaccination landscape.

Missing or inconsistent data emphasizes the need for better global reporting.
